# v1.2-E6 — Release Candidate

Final validation build before v1.2 stable.

## What changed since E5

No gameplay or input behavior was changed.

- Updated README/documentation for the configurable control mapper.
- Removed documentation for the obsolete fixed ZL+X / ZL+Y shortcuts.
- Documented New 3DS vs Old 3DS control availability.
- Simplified GitHub Release titles to the version number only.
- Prepared stable-release cleanup: after v1.2 is published successfully, experimental E-series releases/tags are removed automatically.
- Stable releases remain visible as v1.0.1, v1.1 and v1.2.

## Validated in E5

- Configurable X / Y / ZL / ZR / C-Stick mapping on New 3DS / New 2DS XL.
- X / Y mapping on Old 3DS / Nintendo 2DS.
- Actions: Tabs, Turbo, Item, Save State, Load State and None.
- Item shortcuts use the original game item path without changing visible A/B equipment.
- Mapped controls and item assignments persist between sessions.
- Built-in updater installs newer CIA title versions correctly.

This is the final release-candidate build before v1.2 stable.

The original ROM is not included.
