# v1.2

Stable release of the configurable-controls update for The Minish Cap 3DS.

## Highlights

- Configurable button mapping.
- New 3DS / New 2DS XL: X, Y, ZL, ZR and C-Stick.
- Old 3DS / Nintendo 2DS: X and Y.
- Available actions:
  - None
  - Cycle bottom-screen tabs
  - Turbo
  - Item shortcut
  - Save State
  - Load State
- Item shortcuts use the original game item logic without changing the visible A/B equipment.
- Held items preserve their normal press/hold/release behavior.
- Control mappings and selected item shortcuts persist between sessions.
- Removed the old fixed Roll Attack-on-Y behavior.
- Removed fixed ZL+X / ZL+Y save/load shortcuts in favor of configurable actions.
- Fixed native 3DS soft-slot input handling.
- Fixed CIA title-version handling for reliable built-in updates.
- Simplified GitHub release naming and documentation.

## Defaults on New 3DS

- X → Cycle tabs
- Y → None
- ZL → None
- ZR → Turbo
- C-Stick → Turbo

This release keeps all v1.1 features, including Pixel Perfect Full View, dual-screen UI, Quick Save/Load, QoL options, Randomizer, RetroAchievements and the built-in updater.

The original ROM is not included.
